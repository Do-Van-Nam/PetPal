# 🐾 PetPal - Ứng dụng Quản lý Thú cưng Toàn diện

**PetPal** là một ứng dụng di động hiện đại được thiết kế để giúp những người yêu động vật quản lý và chăm sóc thú cưng của mình một cách khoa học và dễ dàng nhất. Từ việc theo dõi sức khỏe, lịch trình hoạt động đến việc lưu giữ những khoảnh khắc đáng yêu, PetPal là người bạn đồng hành không thể thiếu cho mọi "sen".

## ✨ Tính năng Nổi bật

- **Quản lý Hồ sơ Thú cưng:** Lưu trữ thông tin chi tiết về tên, giống loài, giới tính, cân nặng, ngày sinh và màu lông. Hỗ trợ hàng trăm giống loài khác nhau.
- **Theo dõi Hoạt động:** Lập lịch trình cho các hoạt động như ăn uống, đi dạo, tiêm phòng hoặc khám định kỳ. Nhắc nhở thông minh giúp bạn không bỏ lỡ bất kỳ sự kiện nào.
- **Khoảnh khắc Kỷ niệm:** Lưu trữ và quản lý album ảnh chất lượng cao cho từng thú cưng. Bạn có thể thêm chú thích và chia sẻ những bức ảnh đẹp nhất.
- **Hệ thống Đa ngôn ngữ:** Hỗ trợ đầy đủ Tiếng Việt và Tiếng Anh, giúp người dùng dễ dàng tiếp cận và sử dụng.
- **Kiến trúc Hiện đại:** Ứng dụng được xây dựng trên nền tảng BLoC giúp quản lý trạng thái mượt mà và ổn định.

## 🛠 Công nghệ Sử dụng

- **Framework:** [Flutter](https://flutter.dev) (Dart)
- **State Management:** [Flutter BLoC](https://pub.dev/packages/flutter_bloc)
- **Database:** [SQLite](https://pub.dev/packages/sqflite) (lưu trữ dữ liệu local an toàn)
- **Localization:** [flutter_localizations](https://docs.flutter.dev/accessibility-and-localization/internationalization) (i18n)
- **Navigation:** [GoRouter](https://pub.dev/packages/go_router)

## 🚀 Hướng dẫn Chạy Dự án

Để chạy dự án này trên môi trường local, hãy đảm bảo bạn đã cài đặt Flutter SDK.

1. **Clone repository:**
   ```bash
   git clone <repository-url>
   ```

2. **Cài đặt các dependencies:**
   ```bash
   flutter pub get
   ```

3. **Tạo các file localization (nếu cần):**
   ```bash
   flutter gen-l10n
   ```

4. **Chạy ứng dụng:**
   ```bash
   flutter run
   ```
